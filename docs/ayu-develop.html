Design decisions

Decision Rationale Tradeoff Evidence
Use line buffers and synchronized feed datetimes. Multiple feeds and indicators share a staged callback lifecycle. Preload/runonce are disabled for live or replay modes. Cerebro.run (L1030) / Cerebro._runnext (L1498)

Strengths and limits

Strengths

  • A single strategy API can target a simulator or configured broker. Strategy.buy (L774) / Strategy._next (L346) / BackBroker._try_exec (L1040) / BackBroker.next (L1176)

Limitations

  • Historical fills use OHLC matching and configured slippage. They are not exchange matching-engine replay. BackBroker._try_exec (L1040) / BackBroker.next (L1176)
